Mastercard 官方换算器

本站曾尝试读取万事达官网换算器背后的内部接口，用来展示含点差的参考结算汇率。万事达没有公开的免费 API，该内部接口也没有文档，且官网启用了机器人防护，服务器请求几乎总会被拒绝（常见 HTTP 403）。多次更换请求方式和备用方案后，仍然无法稳定拿到可用数据，因此已去掉自动查询，避免展示过期或错误的汇率。结算汇率含点差，不等于本页中间价，也不代表发卡行最终入账汇率，请以官方换算器为准。

实时汇率数据来自 currency-api（社区维护的免费公开数据）；历史走势（30 / 90 / 180 天）来自欧洲央行参考汇率（经 Frankfurter 提供）；当天分时走势来自 Yahoo Finance 外汇报价。这些均为中间汇率或市场报价，不含任何机构的实际买卖点差。

界面使用 mdui 2（Material Design 3 Web Components）。
